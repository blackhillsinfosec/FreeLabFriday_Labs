# Easy CTF 2 - Hidden Service

An analyst notices that a security tool cannot see a specific Windows service, even though it is clearly running when checked manually.

Further investigation shows an unusual compatibility fix applied to the monitoring application.

---

## Question

What is the attacker most likely trying to achieve?

---

## Flags (Choose One)

-   **A)** Improve system performance
-   **B)** Patch a vulnerable service
-   **C)** Hide the service from the monitoring tool
-   **D)** Enable remote desktop access

---

Correct Flag: **C**
