# Hard CTF - Multi‑Stage Social Engineering Campaign

Your team is investigating a suspected compromise. The following timeline is reconstructed:

1. Public employee information is collected from social media.
2. Targeted emails are sent pretending to be from HR.
3. A user enters credentials into a fake login page.
4. Minutes later, a cloud admin account creates new API keys.
5. Large data downloads begin from cloud storage.

---

## Question

Which stage allowed the attacker to bypass technical controls?

---

## Flags (Choose One)

- **A)** Collecting OSINT on employees
- **B)** Sending the initial phishing email
- **C)** Using a cloud storage service
- **D)** Capturing valid credentials from the fake login page

---

Correct Flag: **D**
