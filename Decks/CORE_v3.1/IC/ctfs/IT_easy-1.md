## Suspicious User Activity

A security analyst reviews login events for an employee account.

You see the following timeline:

```
08:55  Login from office IP
09:10  Access to HR payroll files
09:12  Access to engineering source code repo
09:15  Large download (~2 GB)
```

The employee normally works in marketing and has never accessed engineering systems before.
