# Easy CTF 2 - Login Pattern Analysis

A monitoring dashboard shows a sudden spike in login attempts.

Summary:

```
2,400 login attempts in 15 minutes
300 different usernames targeted
Same password length across attempts
User-Agent strings are nearly identical
```

---

## Question

Which indicator best suggests this is an automated credential stuffing attack?

---

## Flags (Choose One)

- **A)** Many different usernames targeted in a short time
- **B)** The website had high traffic that day
- **C)** Some users logged in successfully
- **D)** The logs include browser User-Agent strings

---

Correct Flag: **A**
