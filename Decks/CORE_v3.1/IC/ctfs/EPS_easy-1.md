## Identifying Spray Behavior

You are reviewing authentication logs from an internet-facing login portal.

```
10:01  user.alex   FAILED_LOGIN   185.199.10.5
10:01  user.maria  FAILED_LOGIN   185.199.10.5
10:02  user.john   FAILED_LOGIN   185.199.10.5
10:02  user.sara   FAILED_LOGIN   185.199.10.5
10:03  user.lee    SUCCESS_LOGIN  185.199.10.5
```

All attempts used the **same password**.
