# Easy CTF 1 - Suspicious Email Analysis

A user reports an email that looks like it came from internal IT support.

```
From: it-support@company-helpdesk.com
Subject: Urgent Password Reset Required

Hello,
Your account will be disabled in 30 minutes unless you verify it now.
Click here: http://company-security-check.com/login
```

The user says they do not recognize the sender domain.

---

## Question

Which clue most strongly suggests this is a social engineering attempt?

---

## Flags (Choose One)

- **A)** The message uses urgency and a look‑alike domain
- **B)** The email contains a password reset request
- **C)** The message was sent during business hours
- **D)** The email uses plain text instead of HTML

---

Correct Flag: **A**
