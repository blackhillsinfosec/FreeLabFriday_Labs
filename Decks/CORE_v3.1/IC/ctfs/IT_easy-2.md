# Easy CTF 2 – Basic Log Correlation

You are reviewing SIEM alerts generated during a routine shift.

Logs show the following sequence for one user account:

```
12:02  VPN login
12:04  Disabled endpoint protection service
12:06  Accessed shared finance folder
```

No maintenance or admin work was scheduled at this time.

---

## Question

What should concern you the most?

---

## Flags (Choose One)

- **A)** The VPN login happened at noon
- **B)** The user accessed a shared folder
- **C)** Endpoint protection was disabled before data access
- **D)** The logs were collected by the SIEM

---

Correct Flag: **C**
