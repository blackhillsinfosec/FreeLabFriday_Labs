## Event Log Digging

```

Service Name:   NetMonSvc
Service File:   C:\Temp\netmon.exe
Service Type:   Win32OwnProcess
Start Type:     Auto Start
Account:        LocalSystem
```

The machine belongs to a standard employee with no admin responsibilities. It is 2 AM.
