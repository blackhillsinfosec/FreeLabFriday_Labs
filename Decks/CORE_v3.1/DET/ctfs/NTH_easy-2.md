# Easy CTF 2 – Basic C2 Detection

While reviewing DNS logs, you notice one endpoint making thousands of DNS queries with long random-looking subdomains.

Example:

```
ajd82ks9s0d.example-domain.com
q8x9sld0a7f.example-domain.com
```

Each query is unique and appears every few seconds.

---

## Question

What technique is the attacker MOST likely using?

---

## Flags (Choose One)

- **A)** DNS tunneling for command-and-control
- **B)** Normal browser cache refresh
- **C)** Network time synchronization
- **D)** Software license validation

---

Correct Flag: **A**
