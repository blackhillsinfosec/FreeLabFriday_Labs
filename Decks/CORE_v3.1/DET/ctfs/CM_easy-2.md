# Easy CTF 2 - Identifying the Scope

Ransomware has been detected on three workstations in the finance department. The IR team lead asks you to help determine the scope of the incident before any recovery steps begin.

You check the network logs and find that all three machines communicated with the same internal file server (FS-01) in the 30 minutes before encryption started. FS-01 is shared across multiple departments.

---

## Question

What does this information tell you about the scope of the incident?

---

## Flags (Choose One)

- **A)** FS-01 should be checked immediately - other departments may also be affected
- **B)** The file server is definitely the attacker's entry point into the network
- **C)** The incident is limited to the three finance workstations only
- **D)** The incident is over since only three machines were encrypted

---

Correct Flag: **A**
