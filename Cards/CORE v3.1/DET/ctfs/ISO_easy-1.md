# Easy CTF 1 - Blocked but Not Gone

You are a SOC analyst responding to an alert. A workstation on the internal network has been flagged for suspicious outbound traffic. Your team has already applied a network-level isolation by disabling its switch port.

A junior analyst says:

> "The machine is isolated, so I powered it off to make sure the attacker can't do anything else."

---

## Question

What is the problem with powering off the machine after network isolation?

---

## Flags (Choose One)

- **A)** Powering off is unnecessary because the switch port is already disabled
- **B)** Powering off destroys volatile evidence such as running processes and memory contents
- **C)** The attacker can reactivate the machine remotely after it is powered off
- **D)** Network isolation only works while the machine is running

---

Correct Flag: **B**
