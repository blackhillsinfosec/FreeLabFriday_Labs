# Medium CTF – Tracking Attacker Movement

You are analyzing activity after a phishing incident.

A workstation was compromised, and shortly after you observe:

```
1) Access to a fake SMB share named: Finance_Archive
2) Read attempts on several decoy files
3) Connection attempt to decoy-db.internal
```

None of these resources are used by real teams.

---

## Question

What does this sequence most likely represent?

---

## Flags (Choose One)

- **A)** Attacker reconnaissance and lateral movement inside the network
- **B)** A user accidentally opening old files
- **C)** Normal file indexing by the operating system
- **D)** Scheduled patching activity

---

Correct Flag: **A**
