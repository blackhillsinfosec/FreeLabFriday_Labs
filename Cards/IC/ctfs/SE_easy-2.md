# Easy CTF 2 - Fake Support Request

An employee receives a phone call from someone claiming to be from the security team.

The caller says:

> “We detected suspicious activity on your account. Please read me your MFA code so I can verify your identity.”

The employee shares the code. Minutes later, an unusual login appears from a new location.

---

## Question

What was the main mistake?

---

## Flags (Choose One)

- **A)** The employee used MFA
- **B)** The attacker called by phone instead of email
- **C)** The employee shared a one-time authentication code
- **D)** The login came from a new IP address

---

Correct Flag: **C**
