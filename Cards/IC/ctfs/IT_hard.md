# Hard CTF – Insider Data Exfiltration Case

You are investigating a potential insider incident.

Network and endpoint logs show:

```
18:03  User connects USB storage device
18:05  Sensitive project files copied locally
18:12  Large encrypted archive created
18:20  Outbound connection to personal cloud storage
```

The user submitted a resignation earlier that day.

---

## Question

Which explanation best fits this scenario?

---

## Flags (Choose One)

- **A)** Routine backup of work files
- **B)** Data exfiltration by a trusted insider
- **C)** Software update activity
- **D)** Automated endpoint scanning

---

Correct Flag: **B**
